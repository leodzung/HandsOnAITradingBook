📋 STEP 1: SIGN UP (2 minutes)
────────────────────────────────────────────────────────────────────────
1. Go to: https://moralis.com
2. Click "Start for Free"
3. Enter email + password
4. Verify email

════════════════════════════════════════════════════════════════════════

🔑 STEP 2: GET API KEY (1 minute)
────────────────────────────────────────────────────────────────────────
1. Log into Moralis dashboard
2. Click profile (top right) → "Account Settings"
3. Go to "API Keys" section
4. Copy "Web3 API Key" (starts with eyJhbGci...)

════════════════════════════════════════════════════════════════════════

⚙️  STEP 3: UPDATE CONFIG (1 minute)
────────────────────────────────────────────────────────────────────────
1. Open: moralis_config.json
2. Replace YOUR_MORALIS_API_KEY_HERE with your actual key
3. Save file

Example:
{
  "api_key": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "base_url": "https://deep-index.moralis.io/api/v2.2"
}

════════════════════════════════════════════════════════════════════════

🧪 STEP 4: TEST (1 minute)
────────────────────────────────────────────────────────────────────────
Run:
    python3 run_moralis_discovery.py

Expected output:
    ✅ Added 25 high market cap tokens
    ✅ Found 15 gainers, 10 losers

🚀 STEP 5: ENABLE IN CRON (Optional)
────────────────────────────────────────────────────────────────────────
To use Moralis discovery in your hourly scanner:

1. Open: run_with_email_alerts.py
2. Find line: from run_combined import fetch_and_analyze
3. Replace with: from run_moralis_discovery import discover_and_analyze as fetch_and_analyze
4. Save file
