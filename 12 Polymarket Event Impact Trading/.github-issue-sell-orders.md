# Add TradeExecutor SELL Order Support for Position Closing

**Labels:** `enhancement`, `critical`, `live-trading`

## Problem

Position closing currently bypasses TradeExecutor and slippage estimation, assuming infinite liquidity. This works for paper trading but would be **critical risk** for live trading.

### Current Implementation

**Opening positions (✅ Safe):**
```python
result = self.trade_executor.execute_trade(request)  # order_side='BUY'
# - Validates slippage
# - Checks orderbook liquidity
# - Rejects if slippage > threshold
```

**Closing positions (❌ Unsafe for live):**
```python
# src/bots/trader_price_levels.py, _close_position()
exit_prices = self.price_fetcher.get_exit_prices(market_id)
exit_price = exit_prices.yes_price if outcome == 'YES' else exit_prices.no_price

# Just updates database - no slippage check!
self.position_manager.close_position(
    market_id=market_id,
    outcome=outcome,
    exit_price=exit_price,  # Assumes this price is achievable
    exit_reason=exit_reason
)
```

### Risk Example

```
Scenario: Close $500 YES position @ $0.60 bid (from PriceFetcher)
Reality: Only $200 of bids available
Problem: No slippage check - would walk orderbook to $0.55 or fail
Impact:  Lose $25+ on exit from terrible execution
```

## Required Changes

### Option 1: Add order_side parameter
```python
def execute_trade(self, request: TradeRequest, order_side: str = None):
    # Auto-determine if not provided:
    if order_side is None:
        order_side = 'BUY'  # Opening positions (default)
    # For closing: pass order_side='SELL' explicitly
```

### Option 2: Separate method
```python
def execute_close_trade(self, request: TradeRequest):
    # Wrapper that calls execute_trade with order_side='SELL'
    return self._execute_trade_internal(request, order_side='SELL')
```
